# 🏠 Vargas Manutenção em Telhados - Landing Page

## 📖 Sobre o Projeto
Esta landing page foi desenvolvida para a empresa **Vargas Manutenção em Telhados**, especializada em serviços de reforma, impermeabilização, limpeza e conserto de telhados. O objetivo principal do site é apresentar os serviços prestados, transmitir confiança e facilitar o contato direto dos clientes através de chamadas para ação (CTAs) estratégicas e botões de WhatsApp.

🌐 **Acesse o site online:** [🔗 Link do Site em Produção](https://vargastelhados.netlify.app/)

---

## 🛠️ Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização avançada, Flexbox e Grid)
* **JavaScript** (Interatividade, máscaras ou animações)
* **Netlify** ( hospedagem do código)

---

## ✨ Principais Funcionalidades
* **Design Responsivo:** Layout adaptado para smartphones e computadores.
* **Seção de Apresentação (Hero):** Destaque imediato para a proposta de valor da empresa.
* **Seção de Serviços:** Detalhamento dos serviços através de um carrossel de imagens.
* **Call to Action (CTA):** Acesso rápido ao atendimento via WhatsApp para conversão de orçamentos.
